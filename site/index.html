System monitoring

Customizable menu bar indicators, history charts and process lists grouped by app.

Adaptive sampling

A shared scheduler reads only what is needed. Hidden sources stop sampling; Economy, Balanced, Real-time and Custom profiles control frequency.

Fan controls

Read fan speeds by default. Optional Automatic, Manual, 100% and Smart Boost controls require the helper and a successful validation test on your Mac.

RAM and maintenance

Memory pressure insights, app recommendations, disk and cache tools, plus optional management of macOS services.

Inspired by Stats, built with its own approach.

OptiStats is an independent app inspired by Stats by exelban. It adapts selected SMC, sensor and fan-control approaches with MIT attribution, while using its own demand-driven sampling architecture and adding RAM guidance, disk/cache maintenance and a Debloat interface.

Designed for low overhead: shared reads, bounded history and work off the interface thread. Lower resource usage than Stats has not been established in a controlled comparison.

Where does Debloat come from?

The service catalog, comments and presets come from mac-os-debloat by Oleksandr Krupko (MIT). OptiStats provides its own interface to inspect services, choose a preset, review changes and apply or restore supported launchd overrides. It does not run the upstream Python script.

Debloat is optional and runs on request. Disabling services can affect macOS features. Catalog updates are manual downloads from the upstream repository; the catalog and MIT notice are credited in the app.

Install and get started

  1. Download the DMG, open it and drag OptiStats to Applications.
  2. Open OptiStats and choose the indicators you want in Preferences.
  3. For fan control, install the optional helper, enable control and run its validation test.

The download is ad-hoc signed and is not Apple notarized. macOS may require approval in System Settings → Privacy & Security. Fan behavior and performance depend on the Mac and enabled features.

Monitoring stays on your Mac. No telemetry. The optional catalog update connects to GitHub only when you request it. This website uses no analytics, third-party fonts or JavaScript runtime.
