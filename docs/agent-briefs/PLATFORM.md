# Área: App/OptiStats/Platform/ (+ Resources/*/Platform.strings)
Implemente `MacPlatform: PlatformServices` e todos os coletores reais: sistema/chip (sysctl, hw.perflevelN, IORegistry cluster types → CoreTopology), CPU (host_processor_info), memória (host_statistics64, vm.swapusage, memorystatus level), processos (proc_listpids/proc_pidinfo, ProcessSample com start time), GPU (IOAccelerator PerformanceStatistics), disco, rede, bateria (IOPS/AppleSmartBattery), sensores SMC somente leitura (IOKit AppleSMC, catálogo do Core), HID temperatura (dlsym IOHIDEventSystemClient*), IOReport Energy Model via dlsym (potência CPU/GPU/ANE/DRAM), ventoinhas leitura, eventos de sistema (sleep/wake, lock, thermal, low power), SelfUsage (task_info), launch at login (SMAppService), FrontmostAppProviding, memoryProbe. Respeite SourceState (.unsupported/.denied/.failed). Cada coletor numa fila serial; sem leituras sobrepostas.
